# 09. 常见问题

> 适用对象:按"现象 → 根因 → 修复"排查 qiankun 集成问题。
>
> 相关专题:[03-dev-mode.md](03-dev-mode.md) · [04-baseurl.md](04-baseurl.md) · [05-subapp-guide.md](05-subapp-guide.md)

| 现象                                                                                                | 根因                                                                                                                                                                    | 修复                                                                                                                                                                                                                            |
| --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Failed to fetch micro app entry`                                                                   | `name / activeRule / container` 与子应用不一致,或 entry URL 不可达                                                                                                      | 校对四方一致;检查 `VITE_<NAME>_APP_ENTRY`                                                                                                                                                                                       |
| dev 模式 `SyntaxError: Cannot use import statement outside a module`(qiankun 抓 Vite dev server 报) | 子应用没装 `vite-plugin-qiankun`,或装了但没加 `qiankunHeadModuleShim` 补丁 plugin                                                                                       | 子应用 `vite.config.ts` 加 `qiankun(name, { useDevMode: true })` + `qiankunHeadModuleShim` 补丁,`main.ts` 注册 `window.moudleQiankunAppLifeCycles[name] = { bootstrap, mount, unmount }`。详见 [03-dev-mode.md](03-dev-mode.md) |
| dev 模式 `@vitejs/plugin-react can't detect preamble. Something is wrong.`                          | shim 设的 `window.$RefreshReg$` 实际设到了 `window.proxy.$RefreshReg$`(qiankun 沙箱),主应用真 window 上还是 undefined                                                   | shim 里用 `var w = (0, eval)('window')`(indirect eval)拿真正 global window 再设。详见 [03-dev-mode.md](03-dev-mode.md)                                                                                                          |
| 子应用路由跳到根域                                                                                  | 子应用 `router base` 取错(非 qiankun 标准用法)                                                                                                                          | 确认主应用通过 `ctx.navigate('/guid')` 跨应用导航                                                                                                                                                                               |
| 重新进入子应用出现双实例                                                                            | `unmount` 没清空容器                                                                                                                                                    | 子应用 `unmount` 必须 `rootInstance.unmount() + container.innerHTML = ''`                                                                                                                                                       |
| 主题 / 语言切换不响应                                                                               | 订阅回调 payload 解构错误                                                                                                                                               | 监听 `next.theme` / `next.locale`,不是裸值                                                                                                                                                                                      |
| 接口 404                                                                                            | 子应用没读 props 的 `baseApi`                                                                                                                                           | mount 时把 `props.baseApi` 注入 fetch 客户端,不要用 `.env.*` 写死                                                                                                                                                               |
| dev 模式接口全部 404(`http://localhost:5173/api/...`)                                               | `baseApi='/api'` 是相对路径,在子应用里 fetch 会解析到主应用 origin(localhost:5173),而 Vite dev server 不代理 `/api/*`                                                   | 主应用用 `getBaseUrl()` 拼出绝对 baseApi 注入 props(Electron dev → `http://127.0.0.1:<__backendPort>/api`)。详见 [04-baseurl.md](04-baseurl.md)                                                                                 |
| 接口 URL 变成 `/api/api/...`                                                                        | endpoint 路径多写了一次 `/api` 前缀(`client.ts` 已用 `baseApi` 拼,不要再写)                                                                                             | `baseApi='/api'` 时 endpoint 用 `/notebooks` 而不是 `/api/notebooks`。约定见 `packages/microapps/notes/src/api/__tests__/client.test.ts`(line 41-56)                                                                            |
| 子应用直 fetch 的资源(Vditor 上传 / 图片 base64)走错地址                                            | 硬编码了 `localhost:<port>` 或相对路径,没有用 `ctx.baseApi`                                                                                                             | 所有 URL 都用 `ctx.baseApi` 拼,不要写死 `localhost:7992`、`/api`、`httpRequest` 之类的常量。详见 [05-subapp-guide.md#36-api-client-约定](05-subapp-guide.md#366-api-client-约定)                                                |
| token 过期子应用自己跳登录页 / 清状态                                                               | 子应用没接 `auth:expired` 事件总线,直接自己处理 401                                                                                                                     | fetch wrapper 捕获 401 时调 `emitAuthExpired('token_invalid')`,由主应用统一清会话 / 跳登录。详见 [05-subapp-guide.md#365-**qiankun**authts--401-事件上报](05-subapp-guide.md#365-__qiankun__authts--401-事件上报)               |
| 重新进入子应用,旧 localStorage 残留(显示上个用户的 token)                                           | `unmount` 没清 `${systemCode}_` 前缀的 localStorage 键                                                                                                                  | `unmount` 里遍历 `Object.keys(localStorage).filter(k => k.startsWith(`${systemCode}\_`))` 删掉。详见 [05-subapp-guide.md#363-maints-必填模式](05-subapp-guide.md#363-maints-必填模式)                                           |
| 重新 mount 报 `createRoot` 重复创建警告 / 双实例                                                    | `mount` 没先 `rootInstance.unmount()`                                                                                                                                   | `mount` / `render` 入口先 `if (rootInstance) rootInstance.unmount()`,再 `createRoot`。详见 [05-subapp-guide.md#363-maints-必填模式](05-subapp-guide.md#363-maints-必填模式)                                                     |
| 子应用 dev 模式能跑,生产白屏                                                                        | 生产构建也装了 `vite-plugin-qiankun`(它给 inline `import()` 加的前缀是 dev-only 门控的,生产会留下解析到 shell base 的相对 specifier);或 `main.ts` 没注册 `window[name]` | 插件只装在 `command === 'serve'`;`main.ts` 里同时写 `window['<name>'] = lifeCycles`。详见 [03-dev-mode.md](03-dev-mode.md) / [06-build-and-deploy.md](06-build-and-deploy.md)                                                   |
| 打包后子应用 404 / 空白(离线、内网)                                                                 | 用了 CDN entry,或 `out/renderer/microapps/` 里没产物                                                                                                                    | 根目录 `bun run build:all`(自动注入 `app://microapps` 基址),或手动 `node scripts/build-micro-apps.mjs`。详见 [06-build-and-deploy.md](06-build-and-deploy.md)                                                                   |
| 生产环境 CORS 报错                                                                                  | 静态资源未配置 `Access-Control-Allow-Origin`                                                                                                                            | CDN / 对象存储配置 CORS;子应用 dev server 已有该 header                                                                                                                                                                         |
| 单独运行能跑,qiankun 模式白屏                                                                       | 缺少 `bootstrap / mount / unmount` 导出,或 `window[name]` 的 name 不匹配                                                                                                | 检查 `main.ts` 的 `window['<name>']` 与 `MICRO_APP_DEFAULTS.name` 一致                                                                                                                                                          |
